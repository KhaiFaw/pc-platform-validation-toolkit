# Sample evidence

`synthetic-failure-report.md` is generated by `platval demo failure` from a real bounded local execution with an intentionally incorrect expected checksum. The platform inventory and timing values are sanitized local observations; the failure itself is explicitly synthetic and must not be interpreted as a hardware defect.

Regenerate comparable evidence locally with:

```powershell
platval demo failure --runtime-dir .platval\sample
```

The generated `.platval` artifacts remain ignored because run IDs, timestamps, fingerprints, and performance observations vary legitimately between systems.
